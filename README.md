# Zomato SQL Subqueries Analysis 🍽️📊

This repository contains SQL queries performed on the **Zomato dataset**, focusing on mastering **subqueries** through real-world data analysis.

---

## Project Overview

The goal of this project is to analyze restaurant data using SQL subqueries and gain deeper insights into:

- Restaurant ratings  
- Cost analysis  
- Location-based insights  s
- Online delivery and table booking trends  

---

## Topics Covered

- Single-row and multi-row subqueries  
- Correlated subqueries  
- Nested queries  
- EXISTS / NOT EXISTS  
- IN / NOT IN  
- Aggregations with subqueries  

---

## Dataset

The dataset used is the **Zomato dataset**, which typically includes:

- Restaurant name  
- Location  
- Cuisine  
- Average cost for two  
- Ratings  
- Votes  
- Online delivery availability
